FFmpeg program

Nestra records your screen with the FFmpeg program. It ships as a separate program, ffmpeg-win-x86_64-v7.1.exe, under the GNU General Public License version 3 or later. It is the gyan.dev 7.1 “essentials” build, unchanged.

The download below holds the complete source code for that program. It includes FFmpeg itself and every library built into it, at the versions it was built with. A list in the download explains where each version comes from.

Download the source (zip)

The file is about 205 MB. Its SHA-256 is 64f105fb63884cbc097584eb33d3cd338c6d194024a84564c55b832a0e7000d5, and every archive inside has its own checksum.
